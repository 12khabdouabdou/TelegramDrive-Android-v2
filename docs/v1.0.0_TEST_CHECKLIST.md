# Telegram Drive v1.0.0 — Test Checklist

## BEFORE INSTALLING (CRITICAL)

1. **Clear app data** on your Samsung device:
   - Settings → Apps → Telegram Drive → Storage → Clear Data
   - (Or: uninstall the old app completely)
2. Install `TelegramDrive-Android_v1.0.0_arm64-v8a_debug.apk`
3. When the app asks for notification permission, **tap Allow**

## WHY v1.0.0

The root cause of "all features broken" was **EncryptedSharedPreferences failing on Samsung Knox**. When Samsung's keymaster invalidated the master key (firmware update, Knox wipe), every access to encrypted prefs threw `AEADBadTagException`. Since both API creds AND the TDLib session key lived there, TDLib couldn't initialize → every feature failed.

v1.0.0 fixes this with a **recovery path**: if EncryptedSharedPreferences fails, the app deletes the corrupted master key + prefs file and retries. If that also fails, it falls back to plain SharedPreferences so the app remains usable.
