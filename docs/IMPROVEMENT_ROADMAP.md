# Telegram Drive (Android) — Comprehensive Improvement Roadmap

> **Scope:** UI/UX overhaul first, followed by critical data-loss/crash bugs, security hardening, AutoBackup/Android 12–15 reliability, media/SAF transfers, performance/DB optimization, architecture cleanup, build/CI/testing, and product feature ideas.  
> **Note:** Every finding below is grounded in direct inspection of `/workspace/TelegramDrive-Android`.

## 1. UI/UX & Design System Improvements (Start Here)

### 1.1 Design System Unification, Light Mode & WCAG Contrast Fixes

1. **Fix broken Light Mode & mismatched `MaterialTheme.colorScheme` (`designsystem/theme/Theme.kt:42-74`)**
   - **Problem:** `MainActivity.kt:70-76` lets users pick Light/Dark/System, yet nearly every screen hardcodes dark `TgColors.Background`, `TgColors.Card`, and `TgColors.TextPrimary`. Selecting **Light** only switches Material 3 controls (`Switch`, `Slider`, `DropdownMenu`, `AlertDialog`), yielding unreadable `#161C2D` text on dark `#102131` surfaces (e.g. `AuthFlow.kt:165-170`).
   - **Fix:** Replace static `TgColors.*` references with `MaterialTheme.colorScheme.*` (or lock the app to Dark Mode and remove the Light option until full light-mode surfaces are migrated). Align `DarkColorScheme` so `primary = TgColors.Primary` (`#FFD395` amber) and `onPrimary = TgColors.OnPrimary` (`#442B00`), with dark `onSecondary`/`onTertiary`/`onError`.

2. **Fix severe WCAG contrast failures (~1.15:1 – 1.6:1)**
   - `FolderScreen.kt:239-240` & `FoldersManagementScreen.kt:74-75`: `FloatingActionButton` sets white icon tint (`Color.White`) on `TgColors.AccentBlue` (`#9DCAFF`) (~1.6:1). Use `TgColors.Primary` + `TgColors.OnPrimary` (or dark `#002F54` on `#9DCAFF`).
   - `AuthFlow.kt:186-191`: `AuthButton` uses `containerColor = TgColors.AccentTeal` (`#66F3B6`) with inherited light `onPrimary` (`#D3E4FA`) (~1.16:1). Explicitly set `contentColor = TgColors.OnPrimary` (dark navy `#031524`).
   - `CreateFolderSheet.kt:74-78`, `RenameFolderSheet.kt:80-84`, `DeleteFolderDialog.kt:58-61`, `ZipBrowserScreen.kt:515`: Default `Button` inherits `onPrimary` `#D3E4FA` on `#9DCAFF` (~1.26:1); `DeleteFolderDialog` also styles a destructive "Delete" button in blue instead of `TgColors.Error` / `ErrorContainer`.
   - `AutoBackupScreen.kt:480-485`: Custom `RadioRow` unselected circle uses `TgColors.Surface` (`#031524`) on `TgColors.Card` (`#102131`) with no border (~1.15:1, nearly invisible).

3. **Consolidate 3 competing design systems & fix component bugs**
   - Merge Deep Space Terminal (`app/res/values/colors.xml`), Editorial (`TgColors.Card`, `EmptyState`, `ProgressRow`, `EditorialCard`), and MD3 Glassmorphism (`GlassPanel`, `EditorialEmptyState`, `EditorialProgressRow`) into one coherent component set.
   - Sync `app/res/values/colors.xml:4` `bg_root` from `#0A0D14` to `#031524` to eliminate the splash-to-UI color flash.
   - Fix `TintedGlassPanel` (`GlassPanel.kt:52-64`), which currently ignores its `tint` parameter completely, and align `TgColors.GlassPanel` (`Color.kt:31`) alpha (`0x66` = 40% vs doc comment claiming 70%).
   - Fix `ConcentricPulse.kt:57`: `delayMillis` inside `tween` pauses *every* animation cycle; use `StartOffset(offsetMillis, StartOffsetType.FastForward)` instead.
   - Bundle `Inter` & `JetBrains Mono` font files in `designsystem/src/main/res/font/` (or remove misleading KDoc in `Typography.kt:10-16`), and raise `bodySmall`/`Caption` from `11.sp` to `12.sp` for legibility.

## 3. Security & Privacy Hardening

1. **Fix exported `DocumentsProvider` Path Traversal (`TelegramDocumentsProvider.kt:168-178`):** `openDocument()` joins unsanitized `file.fileName` to `cacheDir/downloads` and `filesDir/tgdrive_tdlib/files/`, allowing `../../databases/tgdrive.db` or `../../shared_prefs/...` traversal by any SAF client. Resolve real paths safely, enforce `target.canonicalPath.startsWith(allowedRoot.canonicalPath + File.separator)`, and enforce `biometricLockEnabled`.
2. **Eliminate direct `encryptedPrefs` calls bypassing Knox recovery (`KeystoreHelper.kt:57-58, 112-150`):** `safeRead` and `safeWrite` are `private`; `TelegramDriveApp`, `RootViewModel`, `AuthViewModel`, and `SettingsViewModel` read/write `encryptedPrefs` directly and crash with `AEADBadTagException` on Knox key invalidation. Expose typed safe methods (`getApiCreds()`, `saveApiCreds()`), run a canary validation inside `openWithRecovery()`, synchronize `resetSecureStorage()` / `clear()`, fix concurrent recovery race with a generation counter, validate `decoded.size == 32` in `tdlibSessionKey()`, and protect `regenerateTdlibSessionKey()` from wiping API creds.
3. **Audit silent plaintext fallback & deprecated crypto (`KeystoreHelper.kt:85-90`):** Surface `isEncryptionAvailable == false` warning to users rather than silently persisting API credentials and TDLib's 32-byte key in plaintext XML, and plan migration off deprecated `security-crypto:1.1.0-alpha06` to Tink AEAD + DataStore.
4. **Harden Biometric Lock (`MainActivity.kt:123-141`, `SettingsScreen.kt:133-138`):** Persist `biometricLastBgTime` to `AppPreferences` so killing and relaunching the app cannot bypass the lock; require biometric confirmation before enabling or disabling the setting; verify `BiometricHelper.availability()`; set `FLAG_SECURE` on `PasswordForm` and `BiometricGate`.
5. **Tighten `ZipUploader` & `FileProvider` boundaries:** Add zip-bomb bounds (max entry count, max uncompressed size, max compression ratio) and canonical path containment to `ZipUploader.extractZip()`; sanitize `zipName` (`L33`); remove overly permissive `<files-path name="files_root" path="." />` from `app/src/main/res/xml/file_paths.xml:27` (exposes `tgdrive_tdlib/db/`).
6. **Stop logging sensitive metadata in release builds (`Log.kt:15`, `proguard-rules.pro`):** Gate `Log.DEBUG` on `BuildConfig.DEBUG` (instead of `const val DEBUG = true`), scrub paths/IDs from warning logs, and add `-assumenosideeffects` rules in ProGuard to strip `Log.d`/`v`/`i` in release builds.

## 4. AutoBackup & Android Background Execution (Android 12–15)

1. **Fix `ActiveBackupRegistry.tryBegin` TOCTOU & CAS bug (`ActiveBackupRegistry.kt:55-74`):** Initial `BackupPhase.Idle` has `isActive == false`, allowing a second job to overwrite the slot before `Scanning` starts; also `_active.update` mutates external `succeeded` / `_cancelRequested` across CAS retries. Introduce an active `Starting` phase and keep CAS lambda pure.
2. **Preserve terminal `BackupPhase` UI (`BackupWorker.kt:143`):** `BackupWorker.finally` calls `registry.finish()`, wiping `Done`/`Cancelled`/`Failed` cards before users see results or errors. Keep terminal state in registry until user dismisses or a new job claims the slot.
3. **Fix Strict-Mode SHA-256 & `synced_files` duplication (`DiffEngine.kt:174-200`, `SyncedFileEntity.kt:29,33`, `BackupOrchestrator.kt:408-416`):**
   - Compute & store `sha256` on initial upload when `strict == true` (otherwise every file is re-uploaded on run 2 because `null != actualHash`).
   - Add unique index on `(local_path, folder_id)` (or delete-before-insert) so `upsert` updates instead of appending duplicate rows.
   - Only delete `staleRemotePaths` when *every* folder scanned completely without errors/OOM/`MAX_FILES` truncation, and scope `deleteByPath` by `folder_id`.
4. **Fix Android 12–15 Foreground Service restrictions (`BackupOrchestrator.kt:190-201`, `BackupWorker.kt:85-95`):** Periodic/`ON_CHANGE` background runs throw `ForegroundServiceStartNotAllowedException` on API 31+ when calling `setForeground()` unconditionally, aborting backups with a misleading notification-permission error. ## 9. Product Feature Ideas & 4-Sprint Implementation Plan

### 9.1 High-Value Feature Ideas
- **Unified Transfer Center:** Combine active/queued/completed manual uploads, downloads, and AutoBackup jobs in the Transfers tab with pause, resume, retry, and speed/ETA readouts (backed by WorkManager).
- **Offline Pins ("Keep Offline"):** Let users pin important files/folders so they remain downloaded, excluded from cache pruning, and immediately readable via `DocumentsProvider` even without internet.
- **Rich Gallery & Media Experience:** Swipeable folder-wide photo/video carousel, EXIF metadata viewer, video speed/subtitle/gesture seek controls, and in-app syntax-highlighted viewer for text/Markdown/JSON/code files.
- **Smart Duplicate Inspector & Cleanup:** Interactive list inside Storage Analytics allowing side-by-side preview of duplicate groups and one-tap cleanup across chats.
- **Backup Profiles & Retention Policies:** Per-folder destination mapping (instead of one global destination for all local folders), dry-run diff preview before running, and optional auto-prune of old backup ZIPs.
- **Drag-to-Reorder & Virtual Subfolders / Tags:** Custom folder ordering and lightweight tag/virtual-path metadata stored in captions or pinned index messages for nested folder organization.
